Lists the MCP server in the Official MCP Registry as `io.github.odedmoshe/policyseed`. No change to the CLI, the templates or the rendered policies.

## What's new

- **npm package.** `policyseed` is now on npm, so `npx -y policyseed mcp` runs the MCP server without going through GitHub. `npx -y github:odedmoshe/policyseed mcp` keeps working.
- **Official MCP Registry.** `package.json` has an `mcpName` field and the repository has a `server.json`, which the registry uses to check that the npm package belongs to this server.
- The `bin` path in `package.json` is written as `bin/policyseed.js`, the form npm expects, so publishing no longer prints an auto-correct warning.
